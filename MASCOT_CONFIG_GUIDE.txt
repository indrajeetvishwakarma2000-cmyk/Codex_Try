<!-- ==================== OPTION 1: LOCAL FILE (SAME FOLDER) ==================== -->
<!-- For a file in the same folder as the HTML file -->
<!-- Example: Place "jora-happy.gif" in the same folder as the HTML file -->

const MASCOT_IMAGE_URL = "jora-happy.gif";

<!-- For files organized in a subfolder -->
<!-- Example: Create a "mascots" folder, place "jora.gif" inside it -->

<!-- ==================== OPTION 3: REMOTE URL ==================== -->
<!-- For hosting the mascot on a server or cloud storage -->

<!-- ==================== RECOMMENDED GIF SPECIFICATIONS ==================== -->

GIF Specifications:
- Size: 256px × 256px (will scale to 64px automatically)
- Format: .gif (animated recommended) or .png, .jpg
- Background: Transparent (recommended) or white
- File Size: < 500KB for optimal loading
- Animation: 1-3 seconds per loop (smooth and quick)

Examples of good mascot GIFs:
- Cute owl mascot (standing or waving)
- Friendly robot character
- Animated plant or tree
- Fun animal or creature
- Abstract shape with personality

<!-- ==================== TROUBLESHOOTING ==================== -->

If the mascot isn't showing:

1. Check the file path:
   - Local files: File must be in the SAME folder as the HTML file
   - Subfolders: Use "./" prefix (e.g., "./images/mascot.gif")
   - Remote URLs: Verify the URL is accessible (try opening in browser)

2. Check browser console for errors:
   - Press F12 to open DevTools
   - Go to "Console" tab
   - Look for 404 errors or CORS warnings

3. Verify file format:
   - Supported: .gif, .png, .jpg, .webp
   - Unsupported: .svg (use PNG instead), .bmp

4. Test with a different image:
   - Try using the default "Showing thumbs up(1).gif" to verify mascot functionality
   - If default works, your GIF file path is incorrect

5. Hard refresh the page:
   - Windows: Ctrl+Shift+R
   - Mac: Cmd+Shift+R
   - This clears the cache and loads the latest file

const getMascotForTime = () => {
    const hour = new Date().getHours();
    const mascots = {
        morning: "jora-coffee.gif",      // 6-11 AM
        afternoon: "jora-working.gif",   // 12-5 PM
        evening: "jora-tired.gif",       // 6-11 PM
        night: "jora-sleeping.gif"       // 12-5 AM
    };
    if (hour < 6) return mascots.night;
    if (hour < 12) return mascots.morning;
    if (hour < 17) return mascots.afternoon;
    return mascots.evening;
};
const MASCOT_IMAGE_URL = getMascotForTime();

<!-- ==================== FOR DEVELOPERS ==================== -->

Advanced Customization:

To add mascot switching based on app state:

1. Add state to the App component:
   const [mascotState, setMascotState] = useState('happy');

2. Create a mascot selector function:
   const getMascotImage = (state) => ({
       'happy': 'mascot-happy.gif',
       'thinking': 'mascot-thinking.gif',
       'celebrating': 'mascot-celebrating.gif'
   }[state] || 'default.gif');

3. Update FloatingMascot component:
   <img src={getMascotImage(mascotState)} alt="Jora Mascot" />

4. Trigger state changes on events:
   setMascotState('celebrating'); // After quiz completion
   setMascotState('thinking');    // When user is navigating

This enables reactive mascot expressions throughout the app!
